# M2 — Машинно-читаемый граф SINERGY Civilization Graph

Статус: **реализована первая каноническая сборка**

## Назначение

M2 переводит человеческую документацию SINERGY из одного README в набор данных, пригодный для программного анализа, графовых баз, визуализации и автоматических проверок.

## Стабильные пространства идентификаторов

- `M001..M150` — мегапроекты и историко-цивилизационный слой;
- `T001..T100` — технологический слой;
- `F001..F100` — современные фронтирные концепции;
- `P...` — люди и авторские группы;
- `I...` — институты и программы;
- `S...` — источники;
- `E...` — рёбра графа;
- `EV...` — записи доказательств.

ID являются техническими ключами и не переводятся.

## Важное ограничение M2

Первоначальные связи между F, T и M создавались как детерминированное семантическое сопоставление по терминологии канонического README. Они не считались окончательно доказанными причинными отношениями.

Именно поэтому M3 заменил грубые связи полноценной типизированной моделью доказательности.

## Проверка целостности

Запуск:

```bash
python tools/validate_graph.py
```

GREEN требует ровно 150 M-узлов, 100 T-узлов, 100 F-узлов, уникальные ID, существование обоих концов каждого ребра и соблюдение модели доказательности M3.
